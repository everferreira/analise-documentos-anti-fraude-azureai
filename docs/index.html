    🕘 Histórico desta sessão

    Como funciona

    1

    OCR local

    O documento é lido pelo Tesseract.js direto no navegador — nenhuma imagem é enviada para servidor.

    2

    Extração de campos

    Nome, CPF, CNPJ, RG, datas, CEP, valores e itens são estruturados com padrões brasileiros.

    3

    Motor de regras

    Validação de dígitos verificadores, cronologia de datas, consistência com cadastro e conferência de somas.

    4

    Score de risco

    Cada falha soma peso (informação/aviso/crítico) e gera o parecer: Aprovado, Ressalvas ou Reprovado.

    Este produto demonstra o pipeline completo de análise anti-fraude com Azure AI: o mesmo motor roda com o provedor Azure AI Document Intelligence no CLI (ver repositório), enquanto o navegador usa OCR local para funcionar sem chave e sem custo.
